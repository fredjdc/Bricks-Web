# Bricks Apps — Mailchimp Asset Library

## Purpose

This document stores the actual email assets used in Mailchimp.

Use this file when:

* writing a new campaign email
* reviewing an existing email before editing
* reusing a prior email structure
* standardizing subject lines, preview text, CTA copy, and body structure
* creating new product flows based on proven formats

This is the content library.
It should contain finalized or near-final email assets, not broad strategy notes.

---

## 1. How to Use This File

Each asset entry should include:

* asset name
* product
* type
* purpose
* subject line
* preview text
* CTA label
* CTA destination
* body copy
* status
* template used
* notes

### Status values

Use one of these:

* Drafting
* Ready for Review
* Approved
* Live
* Archived

## 4. Reusable Subject Line Patterns

These are patterns, not mandatory formulas.

### Invite

* You’re invited to apply for early access
* Early access is opening in small waves
* Want to join the first beta group?

### Reminder

* A quick reminder about early access
* Still interested in joining the beta?
* Last call to complete the short form

### Confirmation

* We received your response
* Your beta response is in
* Thanks, your form was submitted

### Accepted

* You’re in
* You’ve been selected for early access
* Your beta access is ready

### Not Accepted

* Thanks for applying
* Thanks for your interest in the beta
* We’re opening access gradually

### Onboarding

* Here’s how to get started
* Your first step in Bricks Leads
* Start with your first lead

### Feedback

* How is Bricks Leads going so far?
* We’d like your feedback
* What’s working and what isn’t?

---

## 5. Reusable Preview Text Patterns

### Invite

* Complete a short form to be considered for the first beta group.

### Reminder

* We’re still reviewing early users. Complete the form if you want to be considered.

### Confirmation

* We received your submission and will review it soon.

### Accepted

* You’ve been selected. Here’s the next step.

### Not Accepted

* Access is limited for now, but we’ll keep you in mind for future waves.

### Onboarding

* Start quickly with the first action that matters most.

### Feedback

* A short note on what feels clear, confusing, or missing helps a lot.

## 6. Notes on Scope

This file should contain:

* final or working email copy
* subject lines
* preview text
* CTA text
* reusable patterns

This file should not contain:

* broad policy rules
* naming governance
* full operational history
* analytics reporting

Those belong in the other two files.
