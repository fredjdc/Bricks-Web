# Bricks Apps: Social Media Playbook

**Objective:** Publish 2 posts per week across Instagram first, then repurpose across LinkedIn and X when useful, without violating the [Brand Voice Guide](brand-voice-guide.md).

Remember: We do not sell with pressure. We state facts. We earn trust through restraint.

The goal is still conversion. The difference is how we get there: sound useful, specific, and human. Some posts can be direct product notes. Some can be small observations. Not every post needs to feel like a campaign.

---

## 1. Weekly Cadence

### Recommended schedule

Post **2 times per week**.

| Day | Time | Primary use |
|---|---:|---|
| **Tuesday** | **1:00 PM** | Feature/value post |
| **Wednesday** | **6:00 PM** | Use case, trust, or product-depth post |

Use the audience's local time zone:

- **US App Store audience:** start with Eastern Time.
- **Peru / LATAM audience:** use Peru time.

### Cadence rule

Do not post randomly. Each post should have one job:

| Goal | Best content type | Example |
|---|---|---|
| Explain value | Carousel | “Know what you’ll pay each month” |
| Build trust | Static / carousel | “No account. Works offline.” |
| Drive install | Product carousel + CTA | “Download Bricks Scan on the App Store.” |
| Educate the market | Single insight post | “A lower payment is not always a cheaper loan.” |
| Show product depth | Feature walkthrough | Refinance, prepayments, search, Auto-Sort |

## 2. Six-Week Posting Sequence

This is the starting sequence for Instagram. Reuse the same core idea on LinkedIn or X only when the format fits.

| Week | Tuesday, 1:00 PM | Wednesday, 6:00 PM |
|---|---|---|
| **Week 1** | Bricks Calc: Know monthly payment | Bricks Scan: Find the right document |
| **Week 2** | Bricks Calc: See where your money goes | Bricks Scan: Automate after scanning |
| **Week 3** | Bricks Calc: Cut years off your loan | Bricks Scan: Review, sign, share |
| **Week 4** | Bricks Calc: Refinance pays off | Bricks Scan: Private by design |
| **Week 5** | Bricks Calc: Compare loans | Bricks Scan: Works with Apple tools |
| **Week 6** | Bricks Calc: Amortization | Bricks Scan: Full carousel recap |

Learning path:

- **Bricks Calc:** calculate -> understand -> optimize -> compare -> plan
- **Bricks Scan:** scan -> find -> organize -> act -> trust -> use across Apple tools

## 3. Platform Roles

### Instagram

Use for:

- Product screenshots
- Carousel posts
- Short educational captions
- Story reposts with link sticker

Default format:

- Strong screenshot or carousel
- Short practical caption
- Calm CTA
- Up to 3 hashtags

### LinkedIn

Use for:

- Work moments
- Founder/operator notes
- Real estate professional use cases
- More context around product decisions

Default format:

- Problem in the first line
- One concrete app action
- One trust point
- Plain CTA

### X

Use for:

- Short product observations
- Tiny lessons
- Development notes
- Feature announcements

Default format:

- One idea
- One app mention if needed
- No forced CTA every time
