# Documentation Templates

These templates are the only approved starting points for new canonical docs.

## Rules

- Copy the closest template before writing.
- Keep the required section order.
- Replace every placeholder and checklist item before moving a file to `needs-review`.
- If a section is not applicable, say why instead of deleting it.
- Do not downgrade a canonical doc into notes or freeform prose.
- A doc may move to `active` only after Freddy reviews it against the approval checklist in [`documentation-system-spec.md`](../documentation-system-spec.md).
